# Правила доски

## Колонки
Бэклог → В работе → Ожидание → Ждёт Анну → На паузе → Готово

| Колонка | Что значит |
|---|---|
| Бэклог | Никто не взял |
| В работе | Агент делает |
| Ожидание | Результат или PR ждёт Тестировщика или другого агента |
| Ждёт Анну | Всё проверено, нужен ответ или «да» на «вливаем?», есть ссылка на превью |
| На паузе | Отложено |
| Готово | Влито и проверено |

## Цепочка задачи
БА → дизайнер / данные / юрист → разработка (PR) → Тестировщик (сборка и превью) → Анна получает превью, скрины и вопрос «вливаем?» → после «вливай» PR вливается в main.

## Карточка
Название, колонка, короткий статус со временем, «Кто делает» (пусто = доска выберет), «Модель», «Мощность», метки (например `блокер запуска`), роль (`роль:*`).

## Комментарии
- С агентами общаемся только комментариями карточки.
- На комментарий Анны агент сразу отвечает «Вижу …, делаю: …», потом результатом и «Нормально?».
- Вопросы короткие, варианты строками с «•», рекомендуемый с «★».
- Можно прикладывать файлы и картинки.
- Дизайн всегда как живая превью-ссылка, скриншоты только дополнение.

## Модель и мощность
Поля заполняет Анна. Пусто: агент ничего не меняет. Заполнено: агент переключается перед началом. Координатор в первом ответе называет рекомендуемые модель и мощность, после завершения советует значение для похожей карточки, но сам ничего не меняет.

## Вливание
«Вливай» или «да» на карточке вливает только PR этой карточки. Вливание после двух «ок»: Безопасник и Тестировщик.

## Правила
- Карточка = только то, что просили; лишнее идёт отдельной карточкой.
- Карточки-вопросы Анны (`вопрос Анны`) в «Готово» сами не двигаются: ставятся в «Ждёт Анну» с вопросом «Закрываем?».
- Агенты берут только карточки со своей меткой роли, остальное идёт через координатора.
- Шапка главной зафиксирована.
- Срочное помечается `срочно` и сроком в карточке.
